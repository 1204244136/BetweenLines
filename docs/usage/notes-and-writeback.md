# 备注保存、找回与写回

本文面向审阅和修改文本的使用者。基本流程见 [README](../../README.md)；备注迁移、恢复算法和写回定位的实现要求由 [AGENTS](../../AGENTS.md) 指向的领域契约维护。

## 先保存备注，再写回原文

备注、AI 分析、修改结果与人工确认是审阅记录，编辑它们不会自动改变源文本。显式点击「写回」才会把结果写入输入选择中登记的原始文件。

从控制台打开的翻译工作台会自动把备注保存到电脑，默认目录为 `out/notes/translation-compare/`，面板显示实际位置。使用 `TRANSCOMPARATOR_DATA_DIR` 时，备注位于所配置的数据目录下。重新生成、应用布局、清理旧快照和删除工作台项目都保留长期备注；显式清空或删除备注空间才会移除相应记录。

面板显示「正在保存」或「已保存到电脑」。写盘失败、服务断开或多页面冲突时持续提示「尚未保存」，本页内容保留供重试或导出。请等待保存成功后再关闭页面。

## 找回旧记录与备份

「备注空间与找回」面板区分本页记录和历史空间：

1. 点「预览找回」，查看内容匹配、需核验、本页已有、已合并和未匹配的数量及样例。
2. 确认后补充本页空缺记录；本页已有内容保留，能通过内容核验的历史人工确认可以合并。
3. 对标为「未校验」的行，先核对原文与修改结果，再解除该行隔离。解除隔离不会自动勾选人工确认；写回成功或单独勾选确认后才算人工完成。

首次打开没有记录的空间时，页面会尝试在本项目历史中自动找回。更换输入文件后，请切回对应项目查看旧记录；已有记录或刻意清空的空间不会再次自动搬入旧内容。「应用新布局」只更新页面，保留当前行集与备注空间。

「导出本页」和「备份全部」导出可重新导入的 JSON，包括本页尚未保存的编辑。导入兼容旧版单空间与全空间备份，重复内容跳过，同名但不同内容的记录保留为副本，再由你预览找回。

升级后，当前浏览器来源下的旧记录会迁入电脑。换浏览器、配置档或端口后，已迁入磁盘的记录可通过同一数据目录读取；尚未迁移的旧记录需在原浏览器、配置档或端口打开更新后的工作台，或先导出 JSON 再导入。直接双击 `file://` HTML 只保存到浏览器，要保存到电脑请从控制台打开。

「清空本页」和「清空历史」分别操作当前空间与历史空间，执行前需要确认。其他项目或旧版空间可单独导出、删除，不参与当前项目的找回。

## 写回支持范围与操作

| 工作台 | 可写回格式 |
| --- | --- |
| 翻译比较 | UTF-8 TXT、XHTML / HTML、EPUB 文件、单本解压的 EPUB 目录 |
| 说话人归属 | XHTML / HTML、EPUB 文件、单本解压的 EPUB 目录 |

TXT 写回保留未修改内容、BOM、段首缩进和原有换行格式。带 ruby 等内联标记的段落会保留相应结构。

- **单行写回**：写回并确认当前行。
- **批量写回 / 批量确认**：作用于当前筛选结果，操作前核对确认框中的条数和范围。
- **确认自动不改**：确认全书中 AI 判断无需修改的条目，不受当前筛选限制。

同一控制台服务内，对同一目标的翻译写回和说话人标注依次执行。切换项目后，旧翻译页面的写回会被拒绝；请切回对应项目并重新打开。仅应用新布局、内容未变化时仍可写回。

写回目标是登记的原始路径。早期版本导入的浏览器上传副本仍可读写，页面会提示目标是导入副本。确认框列出范围和备份状态；取消或按 Esc 关闭不会写入。

## 自动备份与恢复

写回自动备份与项目绑定，默认关闭。在翻译工作台「修改结果」操作区或说话人工作台写回区启用后，每次实际写入前会在被改文件旁保留备份：

- 首次为 `原文件名.bak`。
- 后续为 `原文件名.时间戳-随机标识.bak`。
- EPUB 压缩文件备份整本；解压目录只备份被修改的正文文件。

已有备份不会被覆盖或自动删除，备份失败会停止本次写入。恢复时先停止写回，再将需要的备份复制回原路径；确认无须恢复后可自行清理。

确认框中的备份状态以打开确认框时的设置为准。默认关闭时，写回直接修改源文件，使用前请自行留档或启用备份。

## 无法定位时如何处理

写回会用文本、行序和前后上下文确定原文件中的位置。源文件在生成快照后发生变化、同文重复且上下文不能区分，或行序证据矛盾时，会拒绝写入并说明原因。

这些行不会被标为已确认，仍留在复核范围中。先核对源文件与当前快照，必要时重新生成；不要为了消除错误而把其他位置的相同句子当作目标。若仍无法确定位置，手动编辑原文件更合适。
