# 项目存储、快照发布与源文件写回契约

修改项目身份、活动指针、生成发布、快照清理、重渲染或源文件写回前阅读本文。本文拥有持久化边界与写入安全规则；长期备注细则归 [工作台与备注契约](workbench-notes-spaces.md)，输入与行签名归 [文本输入与对齐契约](text-input-alignment.md)，用户操作归根 [README](../../README.md)。

## 运行时数据与不可变快照

- `storage-layout.js`、`project-store.js` 和 `generation-pipeline.js` 将运行时输入、隔离 staging 与已发布快照分开；`out/projects/<projectKey>/snapshots/<snapshotId>/` 是已发布翻译生成物的唯一事实来源。
- 生成成功先通过目录 rename 发布快照，再原子更新 `out/active-project.json`。更新活动指针失败时保留旧副本，不能让失败发布破坏仍可使用的旧项目。
- 项目切换只更新活动指针和小型输入选择，不复制大型生成物。发布后默认保留最新两个快照，并额外保护活动快照；历史清理不能删除当前活动快照。
- `rebuildProjectHtml` 先复制至 staging，重新渲染并发布新快照后再切换指针；不能原地覆盖已发布快照。重渲染保留项目选择与真实行身份，不能借布局更新改变对齐或签名。
- 翻译备注是独立于快照的长期用户数据。快照淘汰与工作台项目删除都保留磁盘备注，具体存储、迁移、保存与删除规则只在 [工作台与备注契约](workbench-notes-spaces.md#长期磁盘存储与旧空间迁移) 维护。
- 说话人工作台使用独立 runtime 产物，不纳入翻译项目快照；不能复用翻译 rows、缓存或 notes 作为持久化容器。

## 身份与服务边界

- `projectKey`、`rowsSignature` 与行 `signature` 是备注空间与写回定位的稳定键。模式裁剪不能改变它们，详见 [模式裁剪与签名](text-input-alignment.md#模式裁剪与签名)。
- 服务入口继续验证 Host、Origin、Sec-Fetch-Site 与 CSRF token。路由、请求体和任务互斥的所有权见 [控制台边界](module-boundaries.md#控制台边界)，不能因重构发布或写回来绕过统一鉴权。
- 页面内嵌的辅助表层只保存文件名；完整路径留在服务端选择和本机状态，运行时从当前项目选择读取原表。辅助表来源、旧快照兼容和空数组语义见 [AI 校对契约](ai-proofread-contract.md#生成前挂载与项目边界)。

## 源文件局部写回

- 写回基于原始输入文件做局部替换，保留不相关的格式与排版，不能以完整重导出覆盖原文件。
- 替换目标依次通过精确内容匹配、上下文锚点和索引范围校验，确认位置唯一。无法唯一定位时放弃该次写入并报告人工介入，不能猜写。
- 维护 ruby、noteref 等内联标签结构与标签对称性；修改文本不能让原有内联结构丢失或损坏。
- 写回只接受用户明确采纳的修改结果，不能把分析字段、待审阶段改案或被终审否决的候选写入成品；最新阶段结果与门禁由 [AI 校对契约](ai-proofread-contract.md#默认修改结果只认末阶段真正采纳的改案) 拥有。

### 自动备份设置

- `.bak` 自动备份是项目级可选项，默认关闭；开启时先保存原文件备份，再执行写回。
- 开关只在工作台：翻译页「修改结果」区和说话人页写回区。控制台不提供重复开关。
- 控制台保存输入选择时若未带 `writebackBackup`，服务端沿用项目已保存取值，不能静默重置为关闭。
- 本机备份含原文，按 [改动工作流](../agents/change-workflow.md) 的数据边界保留在忽略范围，不随代码提交。

## 修改后的验收

快照发布、共享存储或写回实现变化执行 `npm test`，覆盖 staging 发布、原子指针失败、快照保留、项目切换、备注独立性、旧快照重渲染、唯一定位与内联标签保留；定向入口见 [模块边界](module-boundaries.md#控制台边界) 和 [备注测试集](workbench-notes-spaces.md#相关测试集)。写回失败的具体证据与回归见 [排查手册](troubleshooting.md#写回异常)。

代码更新后的服务重启、重新生成或应用布局，统一按 [改动生效与交付提示](../agents/change-workflow.md#改动生效与交付提示) 判断；重启不会替换已发布快照里的页面内容。
