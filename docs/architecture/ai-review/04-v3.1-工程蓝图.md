# 十一、MVP 边界

v3.1 不做：

- 模型投票系统
- 多数决

- 自动微调
- 长期记忆

# 最终目标

把当前 BetweenLines 的 AI 校对系统从“单轮模型评审器”升级为“分层认知审核系统”，同时保持现有 term-table、low-score、web-lookup、format-guard、writeback 全部兼容。
